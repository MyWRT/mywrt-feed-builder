# mywrt-feed-sources

OpenWrt package feed sources for `mywrt`, generated by
[mywrt-feed-builder](https://github.com/MyWRT/mywrt-feed-builder) from upstream
repositories plus local patches. **Do not commit here**: every sync overwrites
the whole tree. Change `sources.toml` or `local-patches/` in the builder instead.

Last updated: **${updated}**

Packages live in `<category>/<name>/` (`luci`, `net`, `utils`, `telephony`, ...).

## Use as a source feed

Add to `feeds.conf`:

```
src-git mywrt https://github.com/MyWRT/mywrt-feed-sources.git
```

then `./scripts/feeds update mywrt && ./scripts/feeds install -p mywrt <package>`.

## Prebuilt packages

```
https://mywrt.awayfrom.cn/packages-<version>/<arch>/mywrt/
```
